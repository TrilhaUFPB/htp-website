# Hack The Path (HTP)

Official website for **Hack The Path**, a hackathon by [Trilha UFPB](https://instagram.com/trilhaufpb) 

Landing page with event info, sponsors, FAQ.

## Quick start

```bash
cd frontend
npm i
cp .env.example .env.local   # Supabase keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
